# Screenshot checklist

Keep public article screenshots in this folder.

Recommended captures:

1. `1500ms-comparison-tr.png` — after verification completes; include both
   result cards, activation/verification times, and critical timeline events.
2. `never-activates-timeout-tr.png` — after timeout; include Approach A's early
   assumption, Approach B's timeout result, and polling events.

Before capturing:

- Use a viewport wide enough to display both cards side by side.
- Reset the simulation before each scenario, or select a new scenario and
  verify that the old timeline has been cleared.
- Keep both cards' measurement panels and the relevant timeline events visible.
- Use the Turkish interface and export PNG files at a readable desktop width.
- Keep the disclaimer visible in at least one screenshot.
- Do not add real device identifiers, profile names, barcodes, or company data.
